# Privacy Policy for The System

**Effective Date:** October 4, 2026

The System is a personal productivity, academic planning, fitness, and self-management application designed for private individual use.

This Privacy Policy explains what information The System may access, how that information is used, and how it is stored.

## Information The System May Access

Depending on which integrations you choose to connect, The System may access information including:

- Calendar events, such as classes, exams, labs, appointments, and other scheduled events
- Academic calendar information imported from Brightspace or other calendar files
- WHOOP fitness and recovery data, including:
  - Recovery score
  - Sleep data
  - Sleep performance
  - Heart rate variability (HRV)
  - Resting heart rate
  - Strain
  - Workout data
  - Cycle data
  - Other related health and fitness metrics made available through the WHOOP API

The System only accesses information required to provide its intended functionality.

## How Information Is Used

Information accessed by The System may be used to:

- Display upcoming classes, exams, assignments, and other events
- Organize academic tasks and deadlines
- Generate study and productivity recommendations
- Identify scheduling conflicts
- Track progress toward personal goals
- Analyze fitness, recovery, sleep, and workload patterns
- Adjust workout or recovery recommendations
- Generate personalized daily plans, quests, reminders, and planning suggestions

The System does not use personal data for advertising.

## Data Storage

The System is currently designed primarily as a local application.

Application settings, imported information, authentication credentials, access tokens, and other personal data may be stored locally on the user's own computer or device.

WHOOP OAuth credentials and tokens are stored by the local backend and are not intentionally exposed through the browser interface.

The System does not intentionally transmit personal information to a separate commercial database unless such functionality is explicitly added and disclosed in the future.

## Sharing of Information

The System does not sell, rent, or trade personal information.

Personal information is not shared with advertisers or data brokers.

Information may be exchanged with third-party services only when necessary to provide features requested by the user. For example, The System may communicate with WHOOP in order to retrieve fitness and recovery information after the user authorizes access.

Those services operate according to their own privacy policies and terms.

## WHOOP Integration

If the user connects a WHOOP account, The System uses WHOOP's authorization process to obtain permission to access selected WHOOP data.

The System may request access to information such as profile, recovery, sleep, cycle, and workout data.

The System does not receive or store the user's WHOOP password.

Authorization can be revoked through the user's WHOOP account or by disconnecting the integration and deleting locally stored authorization data.

Use of information received from WHOOP is limited to providing features within The System.

## Calendar and Academic Data

The System may import calendar information from sources such as Outlook, Brightspace, or iCalendar files.

This information is used to help organize classes, exams, assignments, deadlines, and available scheduling time.

Published calendar links and imported files should be treated as private information. Users are responsible for controlling access to any calendar links they provide to The System.

## Data Retention

Because The System is currently designed to operate locally, personal data generally remains stored on the user's own device until the user deletes it.

Users may delete local application data, imported calendar information, configuration files, or authentication tokens at any time.

## Data Security

Reasonable steps are taken to keep sensitive credentials and authentication tokens separate from the browser-facing portion of the application.

However, no software or storage method can guarantee absolute security.

Users should protect their computer, WHOOP credentials, API credentials, calendar links, and other private information from unauthorized access.

## Children's Privacy

The System is not specifically designed to collect personal information from children under 13.

## Changes to This Privacy Policy

This Privacy Policy may be updated as The System develops or new integrations are added.

Any significant change in how personal information is collected, stored, or shared should be reflected in an updated version of this policy.
